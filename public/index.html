Questions

What is an ATS?

An applicant tracking system is the software employers use to collect and sort applications. It pulls the text out of your CV, files it under headings such as experience and education, and lets recruiters search and rank candidates. If it cannot read your CV properly, a recruiter may never see it.

How is the score worked out?

From checks in four areas: whether the file can be read, structure and layout, content and impact, and spelling and grammar. Each check shows what was found and why it matters. It is a guide based on how these systems commonly behave, not a guarantee for any one employer's software.

Where does my CV go?

Nowhere. Your CV is read, checked and saved in your own browser. Fonts, the dictionary and file-reading libraries are loaded from public CDNs. If you run your own copy with the optional AI proofread switched on, the text is sent to Anthropic's Claude using your own API key.

Does it use AI?

Not on this site. The ATS check, spelling and grammar, templates and downloads are all rule-based and run in your browser. The source code has an optional AI proofread you can switch on if you run your own copy.

Which file should I send to employers?

A PDF made here or a Word file both work with modern systems. If the advert asks for a particular format, use that one.

Is it really free to download?

Yes. The files are created on your own device, so there is nothing to charge for.
